# 국장

코스피·코스닥 전 종목을 **평일 오전(09:50)·오후(14:50, 마감 전)** 에 한 번씩, **과거 데이터로 검증한 기준**으로 점수화해 웹앱(GitHub Pages)에 보여줍니다.
휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 "국장" 아이콘으로 앱처럼 설치됩니다.
안드로이드는 사이트의 **안드로이드 앱(APK) 받기** 버튼으로 설치 파일을 받을 수도 있습니다.

> 정해진 규칙으로 종목을 정렬하는 참고용 도구이며 투자 권유가 아닙니다.

## 점수 기준 (백테스트로 결정)

`screener/backtest.py`로 과거 구간을 검증해서 **실제로 다음 달 주가 상승을 잘 골랐던 지표만** 남겼습니다.

**점수 = 가치 40% + 모멘텀 40% + 저변동성 20%** (조건 통과 종목 안에서의 백분위, 0~100점)

| 지표 | 계산 | 방향 |
|---|---|---|
| 가치 | 같은 업종 안에서 PBR·PER 백분위의 평균 (업종 종목 5개 미만이면 전체와 비교) | 낮을수록 |
| 모멘텀 | 12-1개월 수익률 (최근 1개월 제외 — 단기 반전이 강함) | 높을수록 |
| 저변동성 | 최근 60거래일 일간 수익률 표준편차 | 낮을수록 |

- **대상**: 우선주·스팩·리츠를 뺀 보통주 중 시가총액 1,000억 이상, 거래정지 아님, 순이익·영업이익 흑자, 자본잠식 아님, 매출 정보 있음(은행·보험 등 금융업 제외).
- **보유 목록(매수 관심)**: 점수 상위 **10종목을 10%씩** 담고, 보유 종목은 **순위가 20위 밖으로 밀리거나 매수가 대비 -15%**일 때만 교체합니다. 보유 목록은 실행마다 이어집니다(`data/latest.json`의 `holdings`).
- **신호**: `매수 관심`(보유 목록) · `후보`(20위 안인데 빈자리 없음) · `관망`.
- **내 보유 종목**: 추천 목록에서 `담기`로 실제 산 종목과 매수가를 등록하면, 30위 밖으로 밀려도 전체 순위표(`latest.json`의 `all`)로 계속 추적하고 `보유 유지` / `매도 검토`(20위 밖·매수가 대비 -15%·분석 대상 제외)를 알려줍니다. 목록은 기기(앱·브라우저)에만 저장되고, 앱은 알림창에 내 종목을 실시간 가격·수익률과 함께 우선 표시합니다.
- ROE·성장률·부채비율·FCF·외국인/기관 수급·시장 국면은 **참고 정보로만** 보여줍니다.
- 경고 표시: `가치함정 주의`(PBR<1인데 ROE<8%), `고부채`(부채비율>200%), `FCF 적자`, `일회성 이익 의심`(순이익이 영업이익의 1.5배 초과), `이익의 질 낮음`(영업현금흐름<순이익), `흑자전환`.

### 검증 결과 (2019.04 ~ 2026.07, 88개월)

매달 말, **그 시점에 공개돼 있던 사업보고서 원본**(`screener/fetch_history.py`로 받은 2018~2024년 + 2025년)과 그날까지의 주가만으로 점수를 매겨 상위 종목을 사고, 다음 달 수익률을 쟀습니다. 거래비용 0.3%(교체분) 반영.

| 방식 | 연수익 | 샤프 | 최대 낙폭 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026(~7월) |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **새 모델** (가치40·모멘텀40·저변동20, 10종목, 20위 밖 교체) | **25.6%** | **1.00** | **-25.8%** | -8% | +30% | +12% | **+2%** | +12% | +23% | +114% | **+9%** |
| 이전 모델 (재무60·기술40) | 31.0% | 0.81 | -49.5% | -14% | +141% | +33% | -29% | -9% | +19% | +211% | -26% |
| 가치(PBR·PER)만 | 17.6% | 0.62 | -30.8% | -14% | +67% | +30% | -5% | +8% | -15% | +85% | -15% |
| 조건 통과 종목 전체 동일가중 | 10.2% | 0.40 | -33.0% | -13% | +45% | +7% | -4% | +8% | -3% | +46% | -17% |

알게 된 것
- 새 모델은 이전 모델보다 연수익은 조금 낮지만 **하락장(2022, 2026)에서 버텼고 최대 낙폭이 절반**입니다. 이전 모델의 수익은 2020·2025 급등장에 몰려 있었습니다.
- 업종 안 저PBR·저PER(IC t값 6.4)과 저변동성(t값 4.9)이 7년 내내 가장 꾸준했습니다. ROE·성장률·부채비율은 효과가 거의 없었습니다.
- 최근 1~3개월 급등, 상승일 거래량 급증, RSI·200일선 위 추세는 다음 달 수익률과 **반대**로 움직였습니다(한국 시장의 단기 반전).
- 12-1개월 모멘텀은 단독으로는 효과가 없지만, 빼면 연 10.8%로 떨어져 가치·저변동과 함께일 때 꼭 필요했습니다.
- 매달 전부 교체(연 19.8%)보다 20위 안이면 계속 보유(연 25.6%)가 낫고, 보유 종목은 10개가 15개(23.0%)·20개(18.8%)보다 나았습니다.
- 코스피 200일선 기준 비중 축소와 2×ATR 손절은 수익을 깎았습니다.

한계: 현재 상장 종목만 대상(상장폐지 종목 제외 → 실제보다 좋게 나올 수 있음), 과거 시가총액은 현재 주식 수로 추정, 수급·FCF는 과거 데이터가 없어 검증 못함. **과거 성과가 미래 수익을 보장하지 않습니다.**

백테스트 데이터: Actions의 "과거 재무 받기 (백테스트용)" 워크플로가 DART 키로 2018~2024년 사업보고서를 받아 `gh-pages`의 `cache/dart-history.json`에 저장합니다. 백테스트: `python -m screener.backtest --dart-cache <cache/dart-2025.json> --out backtest` (`build_panel(..., history=)`에 `dart-history.json`을 넘기면 7년 검증).

## 데이터 출처

- **시세·일봉·수급·업종·지수·환율**: 네이버 증권 API(장중 실시간). 실패하면 FinanceDataReader의 KRX 목록(전일 종가)으로 대체합니다. 네이버 API는 비공식이라 예고 없이 바뀔 수 있습니다.
- **재무**: 금융감독원 OpenDART의 사업보고서(연간). 4월부터는 직전 연도 보고서를 쓰고, 아직 공시하지 않은 회사는 그 전 연도 보고서를 씁니다. 연결재무제표를 우선하고, 없으면 별도재무제표를 씁니다.

재무 수치는 1년에 한 번 바뀌므로 DART 결과는 `gh-pages` 브랜치의 `cache/`에 저장해 **7일간 재사용**합니다. 조회 도중 연결이 끊겨도 받은 만큼은 캐시에 남아 다음 실행이 이어서 받습니다. 오전·오후 결과의 차이는 주로 가격·차트·수급 변화에서 생깁니다.

## 설정 (처음 한 번)

1. **DART 키 등록**: 저장소 Settings → Secrets and variables → Actions → New repository secret → 이름 `DART_API_KEY`, 값에 OpenDART 인증키를 넣습니다.
2. **첫 실행**: Actions 탭 → "국장" → Run workflow. 주말이나 휴장일에는 `휴장일이어도 실행`을 체크합니다. 실행이 끝나면 `gh-pages` 브랜치가 생깁니다.
3. **Pages 켜기**: Settings → Pages → Source를 "Deploy from a branch", 브랜치를 `gh-pages` / `(root)`로 지정합니다. 몇 분 뒤 `https://<계정>.github.io/<저장소>/`에서 대시보드를 볼 수 있습니다.
4. 예약 실행(cron)은 **기본 브랜치**에 있는 워크플로만 돌아갑니다. 이 코드가 기본 브랜치에 있어야 합니다.

GitHub Actions의 예약 실행은 붐비는 시간에 10~20분 늦어질 수 있습니다. 휴장일에는 네이버 시세의 마지막 체결일을 보고 자동으로 건너뜁니다.

## 로컬 실행

```bash
pip install -r requirements.txt pytest
python -m pytest -q
DART_API_KEY=발급받은키 python -m screener.main --out public --force
python -m http.server -d public 8000   # http://localhost:8000
```

옵션: `--top 30`(발표 종목 수), `--min-market-cap 1e11`(원 단위), `--min-trading-value 1e8`.

## 안드로이드 앱(APK)

`android/`는 웹앱 주소를 전체 화면으로 여는 WebView 앱입니다. 분석 결과는 웹에서 불러오므로 매일 결과가 바뀌어도 APK를 다시 설치할 필요가 없습니다. 외부 링크(네이버 종목 페이지)는 브라우저로 열립니다.

```bash
cd android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
cp app/build/outputs/apk/release/app-release.apk ../web/josangwon-stock.apk
```

**상위 3종목 표시**
- **알림창 표시**: 매수 관심 종목 전부(최대 10개)의 이름·실시간 가격·등락률을 알림창(내려서 보는 패널)에 소리·진동·팝업 없이 띄워 두고, 마지막 줄에 갱신 날짜·시각을 보여줍니다. 매수 관심 종목이 없으면 종합 상위 3종목을 보여줍니다(안드로이드 13 이상은 처음 실행할 때 알림 허용 필요).
- **위젯**: 홈 화면에 "국장 TOP3" 위젯을 추가할 수 있습니다. 잠금화면 위젯을 지원하는 기기에서는 잠금화면에도 올릴 수 있습니다.
- 30분마다(와이파이·데이터 연결 시) 최신 분석 결과와 네이버 실시간 시세로 갱신하고, 재부팅 후에도 이어갑니다.

디버그 키로 서명합니다. 다른 컴퓨터에서 다시 빌드한 APK는 서명이 달라서, 기존 앱을 지운 뒤 설치해야 합니다.

## 구조

```
screener/market.py     시세·일봉·수급·업종·지수·환율 수집 (네이버, 시세는 FDR 대체)
screener/dart.py       OpenDART 수집(재시도 포함), 계정 추출, 현금흐름 계산
screener/scoring.py    재무 지표, 필터, 업종 내 백분위 점수, 경고
screener/model.py      백테스트로 정한 점수 모델(가치·모멘텀·저변동)과 보유 목록 규칙
screener/backtest.py   과거 구간 백테스트(지표별 IC, 포트폴리오 성과)
screener/fetch_history.py  백테스트용 과거 사업보고서 재무 받기 (Actions: dart-history.yml)
screener/technical.py  이동평균·RSI 등 기술 지표, 시장 국면(참고 정보)
screener/main.py       실행 진입점, DART 캐시, 결과 JSON·히스토리 저장
web/                   웹앱 (index.html, app.js, style.css, manifest.json, 아이콘, APK)
android/               안드로이드 앱 (WebView + TOP3 위젯·알림창 표시)
.github/workflows/screener.yml  평일 2회 실행 후 gh-pages에 게시
```
