# 메모 (Lock Screen One-Line Memo)

휴대폰 **잠금을 풀지 않고** 잠금화면에서 바로 **한 줄 메모**를 남기는 안드로이드 앱입니다.

## 기능

| 어디서 | 어떻게 |
| --- | --- |
| 잠금화면 알림 | 알림 하나에 메모가 한 줄에 하나씩 표시됩니다(제목 없이 내용만, 접힌 상태 3줄 · 펼치면 10줄). 날짜 있는 메모는 지금 시각과 차이가 작은 것부터 자동 정렬되고, 날짜 없는 메모는 그 아래 직접 정한 순서대로 나옵니다. 정해진 시각 앞뒤 2시간 동안은 가까워질수록 글자색이 주황 → 빨강으로 점점 진해집니다(5분마다 갱신). 메모가 하나도 없으면 알림을 띄우지 않습니다. 알림을 펼쳐 **한 줄 메모** 버튼을 누르면 알림 안에서 바로 입력·전송됩니다. |
| 잠금화면 알림 → **크게 쓰기** | 잠금화면 위에 입력창이 뜹니다. 저장하면 곧바로 잠금화면으로 돌아갑니다. |
| 빠른 설정 타일 | 상단바를 내려 **한 줄 메모** 타일을 누르면 같은 입력창이 뜹니다. (타일은 빠른 설정 편집에서 추가) |
| 잠금화면 배경 (선택) | **잠금화면 배경에 메모 표시**를 켜면 메모를 잠금화면 배경화면에 한 줄씩 그립니다. 폰이 알림을 겹치거나 묶어도 영향이 없습니다. 이때 알림은 입력용 하나만 남습니다. 배경 사진은 직접 고를 수 있고, 끄면 잠금화면은 홈 화면 배경으로 돌아갑니다. |
| 앱 | 전체 메모 목록 확인, 추가(날짜·시간 지정 가능), 눌러서 날짜·시간 변경, 꾹 눌러 끌어서 순서 변경(날짜 없는 메모), 오른쪽 🗑 버튼으로 삭제, 잠금화면 표시 켜기/끄기 |

- **📅 날짜·시간 / ⏱ 남은 시간**: 앱과 잠금화면 입력창(크게 쓰기·타일)에서 날짜·시간을 직접 고르거나, “30분 후·2시간 후”처럼 남은 시간으로 정할 수 있습니다.
  어느 쪽이든 정해진 시간과 남은 시간이 함께 보입니다(`오늘 14:00 · 2시간 30분 남음`).
  잠금화면 알림에서는 하루 이내면 남은 시간이 초 단위로 실시간으로 줄어들고, 그보다 멀면 `D-3`으로 보입니다.
  지난 일정에는 “(지남)”이 붙습니다.
  날짜가 바뀌거나 일정 시각이 지나면 표시(오늘/내일/지남)가 자동으로 갱신됩니다.
  알림 속 **한 줄 메모** 버튼으로 바로 쓰는 메모는 날짜 없이 저장됩니다.
- **정해진 시간 전체 화면 알림**: 남은 시간이 0이 되는 순간 소리·진동 없이 잠금화면 위에 화면 전체로 메모를 띄웁니다(정확한 알람 사용). **끄기**를 누르기 전까지 계속 떠 있습니다(뒤로가기로 안 닫힘, 다른 화면으로 가거나 알림을 밀어도 다시 뜸, 재부팅 후에도 다시 뜸). 상태바·내비게이션 바까지 숨겨 화면을 꽉 채우며, ‘다른 앱 위에 표시’를 허용하면 폰을 쓰는 중에도 팝업 대신 전체 화면으로 뜹니다.
  Android 14 이상은 설정에서 ‘전체 화면 알림’ 허용이 필요하며, 앱 첫 화면에 바로가기가 나옵니다. 폰을 쓰는 중이면 화면 위쪽 팝업으로 뜹니다.
- **⌨ 직접 입력**: 키보드로 일·시간·분·초를 입력하면 지금부터 그만큼 뒤로 정합니다(초 단위, "90분"처럼 넣어도 됨).
- **남은 시간 휠**: 일·시간·분 휠은 숫자를 눌러 키보드로 입력할 수 있고, 끝에서 끝으로 이어서 돌아갑니다(0시간 ↑ → 23시간, 0분 ↑ → 59분).
- 입력한 줄바꿈은 공백으로 합쳐 항상 **한 줄**로 저장됩니다.
- 알림은 소리/진동 없이 조용히 표시되며, 밀어서 지워도 다시 나타납니다(끄려면 앱에서 스위치 해제).
- 재부팅 후에도 자동으로 다시 표시됩니다.
- 따뜻한 종이 메모 느낌의 화면(다크 모드 지원). 설정은 오른쪽 위 ⚙ 버튼으로 엽니다.
- 메모는 기기 안에만 저장됩니다. 인터넷은 앱 업데이트 확인에만 씁니다.
- **앱 안 업데이트**: 앱을 켤 때(6시간에 한 번) 또는 ⚙ → **업데이트 확인**을 누르면 새 버전을 확인하고, 있으면 받아서 설치 화면을 띄웁니다.
  처음 한 번은 이 앱의 ‘출처를 알 수 없는 앱 설치’ 허용이 필요합니다.

## 빌드

Android Studio로 열거나:

```bash
./gradlew assembleDebug
# 결과: app/build/outputs/apk/debug/app-debug.apk
```

테스트(Robolectric, 알림 개수 확인 + 배경화면 미리보기 `app/build/wallpaper-preview.png` 생성):

```bash
./gradlew testDebugUnitTest
```

요구사항: JDK 17+, Android SDK 35. 최소 지원 버전 Android 8.0 (API 26).

## 업데이트 올리기

앱은 `memo-releases` 브랜치의 `update.json`을 읽습니다. 새 버전은 아래 한 줄로 빌드·업로드합니다(버전 번호는 커밋 개수로 자동 증가).

```bash
tools/publish_update.sh "이번 업데이트 내용"
```

설치된 앱과 **같은 서명 키**(`signing/memo.keystore` 또는 환경변수 `MEMO_KEYSTORE`, `MEMO_KEYSTORE_PASSWORD`, `MEMO_KEY_ALIAS`, `MEMO_KEY_PASSWORD`)로 빌드해야 덮어 설치됩니다.

## 참고

- 잠금화면에 알림 내용이 보이려면 휴대폰 설정 → 알림 → 잠금화면 알림에서 **모든 내용 표시**가 켜져 있어야 합니다.
  삼성은 알림 스타일을 **상세 정보**로, 픽셀은 **무음 알림 숨기기**를 꺼야 합니다.
- 앱 알림 설정이 표시를 막고 있으면(알림 꺼짐, 무음, 잠금화면 숨김) 앱 첫 화면에 원인과 **알림 설정 열기** 버튼이 나타납니다.
- 일부 제조사(삼성 등)는 잠금 상태에서 알림 답장 시 잠금 해제를 요구할 수 있습니다. 그럴 때는 **크게 쓰기**나 빠른 설정 타일을 쓰면 잠금 해제 없이 입력할 수 있습니다.
- 잠금화면 위 입력창에서는 보안을 위해 새 메모 입력만 가능하고, 전체 목록·삭제는 앱에서만 할 수 있습니다.

## 구조

```
app/src/main/java/com/lockmemo/app/
├── MemoStore.kt            # 메모 저장 (SharedPreferences + JSON)
├── DueFormat.kt           # 날짜·시간 표시("오늘 14:00")와 선택 다이얼로그
├── DueChooser.kt          # 입력창의 날짜·시간 칩
├── LockWallpaper.kt       # 메모를 잠금화면 배경화면에 그리기
├── MemoNotifier.kt         # 잠금화면 알림 + 인라인 입력
├── MemoActionReceiver.kt   # 알림에서 입력된 메모 저장
├── QuickMemoActivity.kt    # 잠금화면 위에 뜨는 입력창
├── QuickMemoTileService.kt # 빠른 설정 타일
├── BootReceiver.kt         # 재부팅 후 알림 복구
└── MainActivity.kt         # 메모 목록/설정
```
